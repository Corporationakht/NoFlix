NOFLIX - PAKET SIAP PAKAI

Isi folder:
- index.html: halaman utama
- style.css: desain responsif
- app.js: logika aplikasi dari kode yang sebelumnya kamu berikan
- videos.json: 125 item katalog awal (84 film, 26 serial, 15 anime)

CARA MEMAKAI
1. Ekstrak ZIP ini.
2. Salin ke folder website NoFlix kamu. Buat salinan/backup file lama terlebih dahulu.
3. Buka videos.json jika ingin mengubah judul katalog.
4. Jalankan melalui web server lokal/hosting, bukan membuka index.html langsung dengan file://, karena app.js mengambil videos.json melalui fetch.

CATATAN PENTING
- Daftar ini adalah katalog awal; beberapa metadata seperti sinopsis, genre, poster, dan episode perlu dilengkapi. Poster placeholder hanya untuk tampilan awal.
- Tautan VidLink dibentuk dari ID TMDB untuk film dan episode pertama serial. ID TMDB mengidentifikasi judul, tetapi tidak menjamin embed tersedia.
- Pastikan setiap sumber video yang kamu pakai memiliki izin yang sesuai. Jika sumber embed tidak tersedia atau menolak iframe, ganti nilai video dengan sumber legal yang bisa disematkan.
- Serial/anime hanya diberi contoh Musim 1 Episode 1; tambahkan data episode sebenarnya sebelum dipublikasikan.
- ID dan tahun katalog ini belum diverifikasi satu per satu; cocokkan judul dan ID melalui themoviedb.org sebelum rilis.
